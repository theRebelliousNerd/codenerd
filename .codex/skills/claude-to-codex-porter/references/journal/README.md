# Porter Journal

Use one dated Markdown file per non-routine migration or porter uplift:

`YYYY-MM-DD-short-topic.md`

Each entry records context, source/target evidence, decisions, intentional
non-parity, validation, and reusable lessons. Do not rewrite another run's entry.
When concurrent work needs the same date/topic, add a short unique suffix.

`references/journal.md` is preserved legacy history and is not the destination
for new entries.
