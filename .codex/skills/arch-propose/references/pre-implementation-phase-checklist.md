# Arch-Propose Phase Checklist

## Scope

- [ ] North-star artifact exists.
- [ ] Mode and tier are recorded.
- [ ] Protected-surface use includes --force.
- [ ] Existing code and corpus state were inventoried.

## Research

- [ ] Four independent scout dossiers exist.
- [ ] Repository claims cite real files or symbols.
- [ ] External claims cite primary or official sources.
- [ ] Extend-existing opportunities were analyzed.

## Decision

- [ ] Two or three candidates were compared.
- [ ] Every candidate covers Mangle safety, JIT prompts, wiring, recovery,
      observability, and tests.
- [ ] Interrogation has a pass/fail verdict.
- [ ] Decision record explains rejected alternatives.

## Audit

- [ ] Current state and target state are separated.
- [ ] No invented file:line citations remain.
- [ ] Expand-mode files have keep/revise/replace/add decisions.
- [ ] Open questions are explicit.

## Corpus

- [ ] Minimum manifest is complete or omitted files are justified.
- [ ] IMPLEMENTED_SPEC carries the pre-implementation banner.
- [ ] Status rows do not claim unobserved implementation.
- [ ] TESTING-STRATEGY and ECOSYSTEM-IMPACT exist.
- [ ] Cross-document links resolve.
- [ ] Docs/architecture/INDEX.md is updated.

## Handoff

- [ ] Journal records generated files and compliance results.
- [ ] Corpus-build entry conditions are explicit.
- [ ] User report links exact artifact paths.
