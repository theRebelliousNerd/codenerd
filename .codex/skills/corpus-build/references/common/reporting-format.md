# Fleet Completion Record

Every worker returns:

## Files touched

List exact repo-relative paths.

## Gate evidence

List each command, exit status, and artifact path. Do not write "should pass."

## Interface assumptions

List symbols or contracts not personally verified. Use `none` when empty.

## Wiring evidence

Show the file/symbol chain from entry point to observable result.

## Skips

List every skipped applicable check and the reason.

## Residual risks

State what remains unproven.

Keep the record terse and machine-readable enough for the orchestrator to
reconcile.
