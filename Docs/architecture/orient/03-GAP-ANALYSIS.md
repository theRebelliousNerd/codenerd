## 2. Phase Execution Order

The gap resolution sequence follows strict dependency ordering:

1. **Phase 1: Workspace & Language Foundation** (`GAP-ORIENT-01`, `GAP-ORIENT-13`)
   Establish true repository membership via `internal/workspace` (Lane `L1`) and multi-language AST/CodeDOM parsing (Lanes `P1`, `P2`, `P3`). Without these, orientation walkers either drown in unignored files or fail to parse target source files.
2. **Phase 2: Sensor & Policy Substrate** (`GAP-ORIENT-02`, `GAP-ORIENT-03`, `GAP-ORIENT-04`)
   Construct the streaming git history parser, document lineage engine, and multi-agent ecosystem parser (Lanes `I2a`, `I1`). Assert ground EDB facts and establish Mangle attention filtering.
3. **Phase 3: Derivation & Initialization Integration** (`GAP-ORIENT-05`, `GAP-ORIENT-06`, `GAP-ORIENT-07`, `GAP-ORIENT-08`)
   Wire LLM role classification, non-interactive North Star synthesis, and agent materialization into `nerd init` phase execution (Lanes `I1`, `I2b`).
4. **Phase 4: Discernment, Privacy & Operator Dialogue** (`GAP-ORIENT-09`, `GAP-ORIENT-10`, `GAP-ORIENT-11`, `GAP-ORIENT-12`)
   Deploy tree role classification, private dependency guards, consented MCP configuration merges, and first-boot TUI clarification questions (Lane `O1`).
5. **Phase 5: Spec Alignment, Native Templates & Technical Debt Sensors** (`GAP-ORIENT-14`, `GAP-ORIENT-15`, `GAP-ORIENT-17`, `GAP-ORIENT-20`)
   Construct the unified bipartite unit graph, link sensors, and native format spec template learners. Sensorize unreferenced symbols, forwarding shims, and dark fields. Derive deductive status atoms (`/aligned`, `/behind`, `/ahead`, `/missing`, `/stale`, `/not_trending`) in Mangle.
6. **Phase 6: Foundations-Up Planning, Spec-First Gate & Orphan Dialogue** (`GAP-ORIENT-16`, `GAP-ORIENT-18`, `GAP-ORIENT-19`, `GAP-ORIENT-21`)
   Extend Kahn topological sorting across the unit graph, implementing `start_from(Kind)` direction seeding and parametric ranking (`what_next`). Wire `/next`, `nerd next`, and intent parsing. Enforce the spec-first completion obligation in `coder_safety.mg`. Deploy durable orphan classification through `kernelClarification` and `.nerd/orientation/answers.json`.
7. **Phase 7: Atomic Transactional Refactoring** (`GAP-ORIENT-22`)
   Generalize `repointAndDelete` into polyglot multi-file `CleanupTransaction` with method repointing, cross-file moves, AST syntax validation, post-commit build/test verification, and automatic rollback on regression.
