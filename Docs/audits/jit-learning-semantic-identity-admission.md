# JIT learning semantic identity admission

## Finding and scope

JIT learning retrieval does not enforce compatibility between a query embedding and persisted learning embeddings before semantic ranking. A healthy query from model B can rank an unmigrated model A index when both have the same dimension. The resulting saved fact can become a retrieved prompt candidate, subject to normal Mangle selection and whole-atom budgeting. This is a representation-validity gap, not evidence that the fact is false, an authority bypass, or an observed harmful response.

This addendum proposes concrete JIT caller conformance, not another generic embedding migration system. The existing embedding audit already documents persisted metadata, representation identity, accepted query/document role pairs, and cross-surface adoption left open. Its ownership remains intact. The refinement is the direct JIT learning path and its pre-migration window. No tests, runtime reproduction, provider inference/embedding calls, or benefit measurements were performed. [Existing scope and open adoption](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/Docs/audits/embedding-representation-and-migration.md#L25-L68), [identity contract](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/Docs/audits/embedding-representation-and-migration.md#L164-L184).

## Production path

Factory wiring creates the configured engine, attaches that same engine to the LearningStore, constructs the compiler vector searcher with it, and independently attaches the LearningStore to the compiler. Successful task compilation feeds `Compile.Prompt`, with project/file context, into the production tool loop. This is not a hypothetical adapter disconnected from execution. [Engine attachment](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/system/factory.go#L1702-L1745), [searcher construction](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/system/factory.go#L1791-L1795), [store attachment](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/system/factory.go#L1859-L1860), [execution](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/session/executor.go#L1385-L1448).

The embedding command persists a changed model and instructs restart without automatically forcing migration. [Configuration route](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/cmd/nerd/embedding_cmd.go#L27-L80).

`EmbedQuery` returns only `[]float32`, using the query task when supported. For a nonempty expanded query, `collectLearningAtomsFrom` performs lexical retrieval and, when a vector searcher exists, passes that raw vector to `RecallLearningsByEmbeddingContext`. Its default search timeout is ten seconds. There is no identity postfilter at this caller. This finding does not apply indiscriminately to semantic search: prompt-atom search already checks model stamps. [Query embedding and prompt-atom checks](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/prompt/vector_searcher.go#L39-L137), [learning collector](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/prompt/compiler_db.go#L481-L526).

Learning hits already contain `EmbeddingModelID`, `EmbeddingDim`, and `EmbeddingTask`. However, the existing-index query selects those fields while ordering `vec_distance_cosine` results without an identity eligibility predicate. Per-shard results then undergo global sorting and limiting. Hydration retrieves the full saved body by shard and ID, with decoding, redaction, and a 16384-byte bound; it does not establish representation compatibility. [Hit metadata and hydration](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_search.go#L28-L68), [aggregation](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_search.go#L175-L213), [indexed ranking](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_search.go#L303-L338).

The collector interleaves lexical-first and semantic-next by rank, deduplicates `(shard, id)`, and caps the combined list at five. It does not compare incomparable lexical and cosine scores. Hydrated atoms preserve stored confidence and provenance, are retrieved context rather than mandatory atoms, and use the compilation shard scope. These safeguards remain relevant but do not validate the embedding space. [Hydration and hybrid merge](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/prompt/compiler_db.go#L526-L582).

The selector emits `retrieved_context`; the Mangle rule gives retrieved candidates selection score 100 without rechecking cosine. Normal selection constraints still apply. [Selector](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/prompt/selector.go#L1203-L1210), [candidate rule](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/core/defaults/jit_compiler.mg#L304-L312).

## Unrun counterexample

1. Persist a valid, short learning L through normal learning/reflection processing with model A, dimension D, an appropriate document task, and an indexed vector. Reopen the workspace with model B, whose engine name differs but whose actual dimension is also D. Require a healthy B query and working SQLite vector support. Reopening preserves existing storage rather than clearing the learning index. [Store initialization and save](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/learning.go#L115-L236).
2. Compile on a fresh cache miss while L remains unmigrated, for example before the worker's first tick relative to worker startup. This is a condition, not a claim about every first user turn: startup may consume that interval. Use a nonempty expanded query with no lexical match for L. A future controlled fixture supplies A/B vectors making L the first semantic result; no relationship between real providers' outputs is assumed.
3. Require no SQL/read error and a valid saved body below the hydration bound. With no competing candidates, or a position fitting the five-item hybrid cap, L reaches the retrieved-atom collection. Claim actual prompt inclusion only if normal context, prohibition, conflict, dependency, and whole-atom budget checks admit it.

No high cosine is needed for bounded candidate displacement. With five lexical hits L1 through L5 and only two semantic rows S1 and S2, both from the old space, the five-item merge is L1, S1, L2, S2, L3. L4 and L5 are displaced regardless of the semantic scores. This does not establish that those displaced facts are better or truer. The primary witness is quiescent old-A metadata plus old-A index bytes, not a concurrency race or cache freshness failure.

## Existing controls and their limits

The reflection worker recognizes model, dimension, and task changes and refreshes bounded batches, reduced to sixteen when a positive backlog is detected. Attachment starts a worker without an immediate cycle; its ticker is 45 seconds. Existing index creation alone does not rebuild old rows. Incremental or force migration closes the witness only when both canonical embeddings and index bytes have reached B before the read. A nil force-call result alone is insufficient: index synchronization failures can warn rather than propagate. This is not permanent default failure. [Worker scheduling and refresh](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_worker.go#L353-L499), [ticker interval](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_worker.go#L15-L17), [embedding and index synchronization](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_worker.go#L530-L646), [force path](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_reembed.go#L90-L151).

An explicitly false `reflection.enabled` is preserved and stops the background worker; direct JIT collection can still run with a configured vector searcher. That is another supported unmigrated-index condition, not a claim that a global-disable promise was broken. The main witness does not require it. [Configuration](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/config/reflection.go#L3-L60).

Chat reflection already filters missing or incompatible model/dimension/document-task metadata and supports lexical fallback. That guard wraps chat reflection, not this collector. Query and document tasks need an accepted pair, not literal equality: query maps to `RETRIEVAL_QUERY`, knowledge to `RETRIEVAL_DOCUMENT`. Missing engines/indexes, cancellation, SQL errors, and dimension mismatch are separate fallback/error cases, not the healthy same-dimensional witness. [Chat retrieval](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/cmd/nerd/chat/reflection.go#L64-L117), [existing guard](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/cmd/nerd/chat/reflection.go#L234-L269), [task mapping](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/embedding/task_selector.go#L89-L108).

## Proposed admission contract

Return a typed query embedding carrying its actual producer identity, dimension, and accepted query/document role contract. Pass that descriptor into store semantic retrieval. Do not infer the producer from the LearningStore's current engine: a custom searcher or mid-call engine change can make that inference wrong. Define compatibility handling for legacy raw-vector APIs explicitly, including deprecation or an untyped/unsafe contract rather than silent trust.

Apply eligibility before both per-shard and global top-k selection. Filtering only the returned k hits can discard foreign rows while starving compatible lower-ranked rows. A minimal JIT check using existing hit metadata is useful defense, but is not the complete retrieval solution. Preserve lexical access to old or unknown representations, existing confidence/provenance, and shard qualification. Semantic eligibility is not permission or fact truth.

Bind the identity check to the bytes actually ranked. Canonical embedding updates and index synchronization currently occur separately, so checking only canonical model metadata is insufficient if index bytes remain stale after a partial publication. Consider atomic publication, versioned index metadata, or a safe canonical-vector read path. This is a repair acceptance requirement, not a second reproduced incident. [Publication ordering](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/reflection_worker.go#L485-L495), [canonical transaction](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/store/learning_reflection.go#L230-L268).

Metadata already exists; do not recreate it. Normal admission checks need no additional embedding or LLM calls. Keep existing bounded migration and optional force reembedding rather than requiring an unconditional full rebuild on every store activation.

## Validation and cost accounting

Future validation should use actual store/index code, factory-equivalent wiring, JIT compilation, and a captured scripted provider request without inference. Controlled same-dimensional fake A/B engines with distinct names and known vectors should establish the witness and assert that foreign semantic candidates are excluded. Positive controls must retain same-A retrieval, fully reembedded-B retrieval, and an old-row legitimate lexical match.

Cover mixed corpora with more than k foreign top-ranked rows; missing stamps, wrong tasks, and actual dimension mismatch; accepted query/document role pairs; missing engines/indexes and cancellation; identical IDs in different shards; competing lexical hits and downstream omission; disabled workers and the first-tick window; incomplete force migration and resume. Pause between canonical updates and index synchronization, including failure, to reject falsely stamped index bytes. Change engines concurrently to verify captured producer identity.

Existing learning-evidence test definitions address hydration, qualified full bodies, whole-atom fit, and interleaving/shard IDs, not cross-model admission. Chat guard definitions were inspected, not executed. Neither source inspection nor this fixture design is a measured regression result. [Learning evidence tests](https://github.com/theRebelliousNerd/codenerd/blob/9dcb01b9736bf4763aa3ac391d29f133d73c6611/internal/prompt/learning_evidence_test.go#L10-L54).

Implementation costs include descriptor/interface migration, compatibility handling, SQL predicates and indexes, eligible-row scans, and canonical joins. Measure filtering-before-limit against any oversampling alternative. Atomic publication can increase transaction/lock duration; versioned metadata adds disk and recovery work. Lexical fallback reduces semantic candidate volume but describes compatibility honestly. Optional reembedding incurs provider work, including retries.

Evaluate compatible retrieval precision/recall, index/canonical coverage, fallback reasons, database rows scanned, CPU, allocations, p95 latency, embedding calls, tokens, and cache hits. Compare full-task quality and total turns/tokens/failed work at matched budgets, not merely retrieval speed. No cost or quality improvement is claimed here.
