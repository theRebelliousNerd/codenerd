# This repository is public

Everything tracked here is published. Nothing from the user's private projects goes into it: not their names, paths, package or predicate names, schemas, roadmaps, bug history, or any description of their internals. This covers code, docs, agent and skill definitions, journals, ledgers, commit messages, and test fixtures, in every harness mirror (`.claude`, `.grok`, `.codex`, `.agents`).

- Write what codeNERD does, citing codeNERD paths that exist in this tree.
- A lesson learned elsewhere is restated generically, with no project, path, or product vocabulary, or it is left out.
- Do not add agent or skill text that ports, syncs, or "writes lessons back" from or to another project. A port is a one-way job done outside this repo.
- Before finishing a change that touches docs, agents, skills, or journals, run the private-terms scanner and clear every hit; never copy its denylist into the repo.
