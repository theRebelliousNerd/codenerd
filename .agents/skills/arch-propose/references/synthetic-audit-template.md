# Synthetic .code-audit.md Template

`arch-propose-auditor` writes this file in place of a real code audit. `arch-writer`
consumes it exactly like a code-auditor output. The structure mirrors the 14-section
real audit but substitutes research-derived content for grep'd code.

The "synthetic" flag in the preamble is the single most important signal — it tells
`arch-writer` that `file:line` citations are suspended for greenfield foundation docs.

---
