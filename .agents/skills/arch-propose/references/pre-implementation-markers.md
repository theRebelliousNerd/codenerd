# Pre-Implementation Honesty Rules (codeNERD)

Every document `arch-propose` generates must be honest that no code exists yet.

---

## Rule 1 — IMPLEMENTED_SPEC.md §Implementation Status All-Zero

```markdown
## Implementation Status

> **Status: Pre-Implementation — no code exists yet. Every component below is a planned target.**

| Component | Status | Completion |
|-----------|--------|------------|
| {Component 1} | Not Implemented | **0%** |
| ... | Not Implemented | **0%** |

**Overall: 0% complete**

Unblocking dependencies:

| Dependency | Status | Gate |
|---|---|---|
| `internal/<parent>/...` | Exists / Planned | What must be true before start |
```

If the candidate **extends** existing code, existing rows may cite real `file:line`; NEW behavior stays 0%.

---

## Rule 2 — Header Status Banner

First block after H1 in `IMPLEMENTED_SPEC.md` and foundation docs 00–04:

```markdown
> Last verified against codebase: {YYYY-MM-DD}
> Status: Living Reference Document
> **⚠ Pre-Implementation — target state only; no code exists yet. Generated by arch-propose.**
```

---

## Rule 3 — 02-CURRENT-STATE Must Not Invent Code

- Name planned primary path (`internal/<feature>/` may not exist).
- Inventory **adjacent** real packages with real citations.
- Never describe runtime behavior of missing packages as present tense fact.

---

## Rule 4 — Alignment Scores

`00-ALIGNMENT-VISION-REVIEW.md` scores dimensions 0/5 (Not started) unless a concrete
baseline exists in sibling packages.

---

## Rule 5 — Gap Analysis Is Roadmap

`03-GAP-ANALYSIS` is target-vs-nothing (or target-vs-partial-adjacent). Ordering + gates only —
no person-weeks or dollar costs.

---

## Rule 6 — file:line Citation Policy

- Suspended for planned greenfield files.
- **Enforced** for adjacent existing code and all cross-cutting integration claims.
- Auditor preamble must state synthetic vs expand mode.

---

## Rule 7 — INDEX Registration

`Docs/architecture/INDEX.md` (create if missing): feature goes under **Proposed**, not as a
completed Spec tier.

---

## Rule 8 — codeNERD Surface Honesty

If the design claims Mangle predicates, VirtualStore routes, shard registration, or prompt
atoms, those must appear as **planned** rows — never as already-wired.

---

## Rule 9 — No Time / Cost Estimates

Roadmaps use phase gates and dependency order only.
